# Logo, icon and mascot

| File | Use |
| --- | --- |
| `pikett-logo.svg` | Logo with wordmark on light backgrounds (README, website) |
| `pikett-logo-dark.svg` | Logo with wordmark on dark backgrounds |
| `pikett-icon.svg` | App icon on teal, square with rounded corners |
| `pikett-icon-light.svg` | App icon on a light background |
| `pikett-icon-512.png` | 512 × 512 PNG of the app icon for places that need a bitmap: Slack app, GitHub avatar, social preview |
| `favicon.svg` | Simplified icon for 16 to 32 px (no teeth or eye highlights) |
| `pikett-mascot.svg` | Pikett the marmot, full figure |
| `pikett-flow.svg` | How Pikett handles an alert, for the README, light |
| `pikett-flow-dark.svg` | The same on dark backgrounds |

The wordmark is set in Space Grotesk Bold (SIL Open Font License) and converted to outlines, so the SVGs need no web font.

## Colors

| Name | Hex | Use |
| --- | --- | --- |
| Teal | `#0d5c63` | Primary, icon background, headlamp band |
| Lamp | `#f2a541` | Accent: the lamp, the dot on the i, the light beam, the whistle |
| Fur | `#8b5e3c` | Mascot |
| Fur dark | `#6e4529` | Ears, paws, tail |
| Slate | `#16262a` | Text on light backgrounds |
| Light | `#eef2f1` | Background, text on dark backgrounds |
