# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, criticise code and not people, and help newcomers.

Report unacceptable behaviour privately to the maintainers through GitHub (Security > Report a vulnerability works for this too, if no other contact is listed). Reports are handled confidentially.
